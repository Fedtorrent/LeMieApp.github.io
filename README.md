# Il Mio Portfolio App

Benvenuti nel mio sito portfolio personale, una vetrina per le mie applicazioni Android open source. Il sito è progettato con un'estetica moderna utilizzando **Material Design 3** e i componenti web di Google.

## 🚀 Informazioni sul Progetto

Il sito presenta attualmente **5 applicazioni Android** principali:

1.  **AssetHub**: Monitoraggio del patrimonio e degli investimenti con focus sulla privacy (dati locali).
2.  **La Mia Salute**: Gestione della salute familiare, farmaci, misurazioni e notifiche.
3.  **I Miei Magazzini**: Tracciamento delle scorte con database su Google Drive e supporto multiutente.
4.  **Spese 730**: Registrazione di scontrini e fatture per il calcolo automatico dei rimborsi fiscali.
5.  **I Miei Contatori**: Un'app semplice per tenere traccia di utilizzi ricorrenti o scadenze personalizzate.

## ✨ Funzionalità del Sito

-   **Galleria App Dinamica**: Le schede delle app sono generate dinamicamente tramite JavaScript (`main.js`).
-   **Interfaccia Material 3**: Utilizzo di `@material/web` per pulsanti, schede, dialoghi e icone.
-   **Lightbox Screenshot**: Un visualizzatore integrato per esplorare gli screenshot delle applicazioni senza lasciare la pagina.
-   **Responsive Design**: Layout ottimizzato per dispositivi mobili e desktop.
-   **Call to Action**: Collegamenti diretti ai repository GitHub e ai download degli APK.

## 📲 Come installare le App (APK)

Le applicazioni in questo portfolio sono fornite come file APK per l'installazione manuale su dispositivi Android. Segui questi semplici passaggi per l'installazione:

0.  **Trasferimento al telefono**: Se scarichi l'APK su un PC, trasferiscilo al tuo smartphone per poterlo installare. Puoi usare WhatsApp Web, Telegram, l'invio tramite email o un cavo USB.
1.  **Scarica l'APK**: Clicca sul pulsante "Download APK" nella scheda dell'applicazione che desideri provare.
2.  **Abilita Origini Sconosciute**: Android protegge il tuo dispositivo bloccando le app da fonti diverse dal Play Store. Se è la prima volta, il sistema ti chiederà di autorizzare l'installazione. Vai in **Impostazioni > App > Accesso speciale > Installa app sconosciute** e abilita il permesso per il tuo browser o file manager.
3.  **Conferma l'Installazione**: Apri il file scaricato (solitamente tramite la notifica di download o un file manager) e premi "Installa" quando richiesto.

*Nota: Tutte le applicazioni in questo sito sono sicure e il codice sorgente è disponibile per la revisione su GitHub.*

## 🛠️ Tecnologie Utilizzate

-   **HTML5 / CSS3**: Struttura e stile personalizzato con variabili CSS per il tema Material.
-   **JavaScript (ES6+)**: Logica per il rendering dinamico e la gestione dell'interfaccia.
-   **Material Web Components**: Integrazione della libreria ufficiale di Google per componenti UI coerenti.
-   **Material Symbols**: Iconografia moderna e scalabile.

## 📂 Struttura dei File

-   `index.html`: Punto di ingresso principale del sito.
-   `main.js`: Gestisce i dati delle app e la logica della galleria/lightbox.
-   `style.css`: Contiene le definizioni dei temi e gli stili di layout.
-   `images/`: Directory contenente icone, screenshot e risorse grafiche.
